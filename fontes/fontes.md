# 📚 Curadoria de Fontes

Este projeto utilizou quatro fontes abertas e oficiais da documentação do Python. A seleção foi realizada considerando a necessidade de estudar desde os fundamentos da linguagem até a manipulação de arquivos, diretórios e recursos do sistema operacional.

## Fonte 1 — Documentação oficial do Python

**Título:** Python Documentation

**Link:** https://docs.python.org/3/

**Objetivo da fonte:**
Utilizar a documentação oficial como referência principal para conceitos gerais da linguagem Python, sua biblioteca padrão e recursos disponíveis.

**Motivo da escolha:**
É uma fonte oficial, confiável e mantida pelo projeto Python.

---

## Fonte 2 — Tutorial oficial do Python

**Título:** The Python Tutorial

**Link:** https://docs.python.org/3/tutorial/

**Objetivo da fonte:**
Estudar os fundamentos necessários para uma pessoa iniciante em Python, incluindo tipos de dados, estruturas de controle, funções, módulos, entrada e saída e tratamento de exceções.

**Motivo da escolha:**
O tutorial apresenta os fundamentos da linguagem de forma estruturada e serve como base para a construção da trilha de aprendizagem.

---

## Fonte 3 — Módulo os

**Título:** os — Miscellaneous operating system interfaces

**Link:** https://docs.python.org/3/library/os.html

**Objetivo da fonte:**
Estudar como Python pode interagir com o sistema operacional, incluindo arquivos, diretórios, processos e variáveis de ambiente.

**Motivo da escolha:**
O módulo `os` fornece recursos diretamente relacionados à criação de scripts capazes de executar tarefas relacionadas ao sistema operacional.

---

## Fonte 4 — Módulo pathlib

**Título:** pathlib — Object-oriented filesystem paths

**Link:** https://docs.python.org/3/library/pathlib.html

**Objetivo da fonte:**
Estudar a manipulação de caminhos, arquivos e diretórios utilizando a abordagem orientada a objetos fornecida pelo `pathlib`.

**Motivo da escolha:**
A biblioteca é especialmente relevante para automação de arquivos e diretórios e complementa os conhecimentos estudados no módulo `os`.

---

## Observação sobre a curadoria

Durante os testes realizados no NotebookLM foi identificada uma limitação importante: as fontes não apresentavam uma definição teórica direta de "automação de tarefas".

Esse resultado foi considerado parte do processo de aprendizagem e levou à análise crítica das respostas produzidas pela Inteligência Artificial.

A experiência demonstrou que a qualidade das respostas depende não apenas da elaboração dos prompts, mas também da qualidade, abrangência e adequação das fontes selecionadas.
