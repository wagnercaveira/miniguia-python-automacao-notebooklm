## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte de um Desafio de Projeto da [DIO](https://www.dio.me/), utilizando a Inteligência Artificial como ferramenta de aprendizagem ativa.

O tema escolhido foi:

> **Python aplicado à automação de tarefas**

O estudo foi realizado utilizando o **NotebookLM**, com fontes selecionadas previamente e uma sequência de prompts desenvolvida para explorar, organizar e revisar os conhecimentos obtidos.

O objetivo não foi apenas obter respostas da Inteligência Artificial, mas utilizar a ferramenta como apoio ao processo de aprendizagem, desenvolvendo também habilidades de curadoria, elaboração de prompts e análise crítica das respostas.

---

# 🎯 Objetivos

Os principais objetivos deste projeto foram:

* compreender os fundamentos da linguagem Python;
* entender o conceito de automação de tarefas;
* estudar a utilização de Python na manipulação de arquivos e diretórios;
* conhecer os módulos `os` e `pathlib`;
* identificar possibilidades de automação;
* desenvolver uma trilha progressiva de aprendizagem;
* experimentar diferentes estratégias de elaboração de prompts;
* analisar limitações e possíveis problemas nas respostas da IA;
* criar um material reutilizável para futuras revisões.

# 🧪 Engenharia de Prompts

Foram realizados três testes principais.

### Teste 1 — Prompt inicial

Uma pergunta simples foi utilizada para avaliar a capacidade inicial do NotebookLM de explicar Python e automação.

**Resultado:** a resposta sobre Python foi adequada, mas as fontes não apresentavam uma definição conceitual direta de automação.

---

### Teste 2 — Prompt contextualizado

O prompt passou a especificar:

* público iniciante;
* exemplos práticos;
* utilização das fontes;
* transparência quando as fontes fossem insuficientes.

**Resultado:** a resposta tornou-se mais didática e prática.

---

### Teste 3 — Prompt estruturado

Foi criado um prompt contendo tópicos obrigatórios, público-alvo, critérios de utilização das fontes e orientação para indicar limitações.

**Resultado:** foi obtida uma resposta estruturada em diferentes áreas do conhecimento necessárias para iniciar estudos de Python aplicado à automação.

Os prompts completos e a análise detalhada estão disponíveis em:

# 🩹 Cicatrizes e aprendizados

Durante o projeto foram identificados alguns pontos importantes.

### 1. Fontes insuficientes

O primeiro teste revelou que as fontes não apresentavam uma definição direta de automação de tarefas.

**Aprendizado:** a qualidade da fonte influencia diretamente a qualidade do resultado.

### 2. Importância do contexto

A inclusão do público-alvo e dos objetivos produziu respostas mais adequadas.

**Aprendizado:** prompts mais contextualizados tendem a gerar resultados mais úteis.

### 3. Estrutura melhora a resposta

A definição de tópicos obrigatórios permitiu obter um resultado mais organizado.

**Aprendizado:** especificar o formato desejado facilita a obtenção de respostas alinhadas ao objetivo.

### 4. A IA precisa ser verificada

Uma resposta bem estruturada e convincente ainda pode conter detalhes que precisam ser conferidos na fonte original.

**Aprendizado:** Inteligência Artificial deve ser utilizada junto com análise crítica e validação das informações.
