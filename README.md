# 🐍 MiniGuia de Python para Automação de Tarefas com Inteligência Artificial

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO com o objetivo de utilizar a Inteligência Artificial como ferramenta de aprendizagem ativa.

O tema escolhido para o estudo foi **Python aplicado à automação de tarefas**.

A proposta é utilizar o NotebookLM para organizar fontes de estudo, realizar perguntas estratégicas, comparar respostas, identificar dificuldades e construir um material de consulta que possa ser utilizado posteriormente.

---

## 🎯 Objetivos

Os principais objetivos deste projeto são:

* Compreender os fundamentos da linguagem Python;
* Entender o conceito de automação de tarefas;
* Identificar tarefas repetitivas que podem ser automatizadas;
* Aprender conceitos básicos relacionados à manipulação de arquivos;
* Compreender como scripts Python podem auxiliar na produtividade;
* Utilizar a Inteligência Artificial como ferramenta de apoio ao aprendizado;
* Desenvolver melhores estratégias de elaboração de prompts;
* Criar um material de estudo reutilizável para futuras revisões.

---

## 🤖 Uso da Inteligência Artificial

O NotebookLM será utilizado como ferramenta de aprendizagem e organização do conhecimento.

Durante o desenvolvimento do projeto serão realizadas perguntas e testes de prompts utilizando as fontes selecionadas para o estudo.

O objetivo não é apenas obter respostas da Inteligência Artificial, mas também analisar a qualidade das respostas, verificar suas referências, identificar limitações e aprimorar as perguntas utilizadas.

---

## 📖 Estrutura do projeto

Este repositório será organizado nas seguintes etapas:

1. Contexto e objetivos;
2. Curadoria das fontes;
3. Organização das fontes no NotebookLM;
4. Engenharia de prompts;
5. Registro dos testes e dificuldades encontradas;
6. Construção do miniguia de estudo;
7. Glossário dos principais conceitos;
8. Prompts reutilizáveis;
9. Conclusões e aprendizados.
